# CampusLoop

CampusLoop is a student-to-student campus sharing platform derived from the working architecture of the Raghava Paints & Hardwares dashboard.

## Core idea

Students can share resources in four ways: Give, Sell, Exchange, and Borrow. Students can also post **I Need** requests so people with matching resources can respond.

## Current features

- Campus resource explorer
- Search and category/mode/year filters
- Share a resource
- I Need requests
- Borrow and return tracking
- Personal activity
- Student profile
- Google Drive `.xlsx` storage
- Browser-side SheetJS workbook integration
- Seed/demo data before connecting a workbook

## Planned production layer

1. Campus email / identity verification
2. Student-to-student chat
3. Notifications
4. Ratings and reputation
5. File/resource uploads
6. AI matching for “I Need” to listings
7. Leaving Campus mode
8. Moderation / reporting
9. Real backend/database for multi-user concurrency
